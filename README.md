# Text Summarization Using Deep Learning

An end-to-end **abstractive text summarization project** using state-of-the-art Transformer-based deep learning models, including **BART, T5, and PEGASUS**. The project generates concise, meaningful summaries from long-form text while preserving the key information and context of the original content.

## 🚀 Features

* Abstractive text summarization using Transformer architectures
* Supports **BART, T5, and PEGASUS** models
* Generates concise summaries from long articles or documents
* Compares the performance of different summarization models
* Uses pre-trained models from the Hugging Face Transformers ecosystem
* Easy-to-use interface for entering text and generating summaries
* Evaluates generated summaries using metrics such as **ROUGE**

## 🧠 Models Used

* **BART** – Bidirectional and Auto-Regressive Transformers for high-quality text generation
* **T5** – Text-to-Text Transfer Transformer for flexible NLP tasks
* **PEGASUS** – Transformer model specifically designed for abstractive summarization

## 🛠️ Technologies

**Python | PyTorch | Hugging Face Transformers | NLP | Deep Learning | BART | T5 | PEGASUS | ROUGE**

## 📌 Project Objective

The main objective of this project is to study and compare modern deep learning approaches for automatic text summarization and determine how different Transformer architectures perform when generating summaries from lengthy textual content.

## 📊 Applications

* News and article summarization
* Research paper summarization
* Document summarization
* Content management
* Information retrieval
* Automatic generation of concise textual content
